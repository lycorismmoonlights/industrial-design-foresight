## 内容边界

- 按用户明确要求组织计算机、人工智能、经管参与方向；设计牵头。
- 六周、5–8 人、每周 2–3 小时、证据数量和交付数量均为建议，待负责人、老师和参与者确认。
- 案例的欧盟官方背景已查阅；研究问题、反证线索、需求研究和 AI 评估方案均标明为提案，未宣称已执行。
- 没有把测试通过等同于外部 API、定时任务或付费模型已在线运行；本轮未验证这些运行状态。
- 当前仍是单所有者系统。跨学院试点先用模板提交与集中审核，没有宣称多人账号或团队权限已完成。

## 复现与交接

1. 在项目目录运行 `pnpm exec vinext dev -p 3000`。
2. 打开 `http://localhost:3000/showcase`。
3. 导出：`node scripts/export-showcase.mjs`。
4. 投屏文件：`output/pdf/foresight-collaboration.pdf`。
5. 若需运行 Playwright 配置中的测试服务，先停止同项目已有的 vinext 服务，避免进程锁冲突。

只可将 PDF 和公开共研方案作为目前的离线转发材料。本地 URL 不能跨电脑直接访问；公网展示需后续部署。
